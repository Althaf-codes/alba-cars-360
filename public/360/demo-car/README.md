# Deprecated automotive 360° sequence drop location

Place a licensed, dedicated automotive turntable sequence here only after its
redistribution rights have been verified. The currently configured manifest
expects exactly 24 WebP files:

```text
001.webp
002.webp
...
024.webp
```

Requirements:

- one car, sequentially captured around a fixed center;
- consistent camera, crop, lighting, and background;
- 16:9 frames, with the entire vehicle visible at every angle;
- optimized WebP, ideally 1200–1400px wide for this concept;
- documented license that permits inclusion and redistribution in this project.

This fallback path is not active in the concept. The active Porsche
demonstration sequence is documented in `ASSET_NOTES.md` and lives in
`public/360/porsche-911-carrera-14036ac/`. The existing lazy viewer requests
either path only after the visitor activates “Explore in 360°”.

Do not place ordinary ALBA listing photography here. It is not a turntable
sequence and must remain part of the conventional gallery.
